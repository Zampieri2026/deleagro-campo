# DELEAGRO Campo

Aplicativo web instalável (PWA) para levantamento de campo na investigação de crimes rurais — DELEAGRO / Polícia Civil de Mato Grosso do Sul.

- Ocorrências por natureza (abigeato, máquinas, GPS agrícola, defensivos, grãos, receptação, estelionato, marca, conflito agrário)
- Local do fato com GPS e fotos (com metadados EXIF e hash SHA-256 do original)
- Pessoas envolvidas, bens, checklist de diligências e legislação
- Relatório em PDF único com anexo fotográfico

**Os dados das ocorrências ficam somente no aparelho de cada usuário (IndexedDB). Este repositório contém apenas o código do aplicativo.**

Instalação: abrir o endereço do GitHub Pages no Safari (iPhone) ou Chrome (Android) e adicionar à tela inicial.
